# Project 2: Problem 5 Overview

This project focuses on developing and analyzing algorithms for efficiently building a system of microservices with dependency constraints. We explore both a naive approach and a more efficient graph-based strategy to detect circular dependencies, determine the critical path, and minimize the total build time. As a bonus, the project includes an optimization to identify the dependency edge whose removal would produce the greatest reduction in build time. The project also includes algorithm design, complexity analysis, and implementation details.

See the [planning document](planning.md) for detailed algorithm design and complexity analysis.
